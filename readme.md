# 💰 SpendWise Dashboard

## 📌 About the Project

SpendWise Dashboard is a personal budgeting web application designed to help users calculate their monthly budget, track expenses, and understand their remaining balance.

This project was created as part of my JavaScript learning journey to practice programming fundamentals and build an interactive webpage.

## ✨ Features

* Calculate monthly budgets.
* Calculate total expenses and remaining balances.
* Display budget status.
* Validate user input.
* Interactive Calculate Budget button.
* Responsive dashboard design.
* Learning resources section.

## 🛠️ Technologies Used

* **HTML5** — Structures the webpage.
* **CSS3** — Styles the dashboard and makes the layout responsive.
* **JavaScript** — Handles calculations, conditions, functions, and button interactions.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all project files are in the same folder.
4. Open `index.html` in your web browser.
5. Click the **Calculate Budget** button.
6. Enter your monthly budget and total expenses.
7. Open the browser console to view the calculation results.
